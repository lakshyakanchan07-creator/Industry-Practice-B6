🗄️ Online Grocery Store — Database Design

Relational SQLite schema architecture, 5 normalized core tables, primary/foreign keys, and transactional integrity.

📐 Relational ER Diagram (5 Core Tables)

3rd Normal Form (3NF) Architecture
📁 categories Lookup Table
  • PK category_id INTEGER
  • UNQ name TEXT NOT NULL
👤 users Customer Entity
  • PK user_id INTEGER
  • NN name TEXT NOT NULL
  • UNQ email TEXT NOT NULL
  • NN address TEXT NOT NULL
🍎 products Grocery Items
  • PK product_id INTEGER
  • NN name TEXT NOT NULL
  • FK category_id INTEGER → categories(category_id)
  • NN price REAL NOT NULL
  • NN unit TEXT NOT NULL
  • stock_quantity INTEGER DEFAULT 0
  • image_url TEXT
  • badge TEXT DEFAULT 'Fresh'
🧾 orders Order Headers
  • PK order_id INTEGER
  • FK user_id INTEGER → users(user_id)
  • order_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  • NN total_amount REAL NOT NULL
  • status TEXT DEFAULT 'Pending'
📦 order_items Line Items Bridge
  • PK order_item_id INTEGER
  • FK order_id INTEGER → orders(order_id)
  • FK product_id INTEGER → products(product_id)
  • NN quantity INTEGER NOT NULL
  • NN unit_price REAL NOT NULL

🔗 Foreign Key Referential Integrity & Cardinality

1 : N categories (1) → products (N) • ON DELETE CASCADE
1 : N users (1) → orders (N) • ON DELETE CASCADE
1 : N orders (1) → order_items (N) • ON DELETE CASCADE
1 : N products (1) → order_items (N) • ON DELETE RESTRICT

⚡ 5-Table Relational JOIN Query Verification
Verified Transaction Records

This query executes a relational join across all 5 tables (orders, users, order_items, products, and categories) demonstrating end-to-end data consistency.

SELECT o.order_id, u.name AS customer_name, p.name AS product_name, c.name AS category_name, oi.quantity, oi.unit_price, (oi.quantity * oi.unit_price) AS line_total, o.total_amount, o.status, o.order_date FROM orders o JOIN users u ON o.user_id = u.user_id JOIN order_items oi ON o.order_id = oi.order_id JOIN products p ON oi.product_id = p.product_id JOIN categories c ON p.category_id = c.category_id ORDER BY o.order_id DESC;
